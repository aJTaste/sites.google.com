AppHubとは？

学校生活をより便利にする、学生向けの統合ツールプラットフォームです

chat

ChatHub

リアルタイムチャット機能。ダイレクトメッセージやチャンネルでのグループチャットが可能。画像共有やリプライ機能も搭載。

link

Links

便利なゲームやツールのURLを共有できます。カテゴリー分けで整理され、みんなでおすすめのサイトを共有しましょう。

folder

Files

あらゆる形式のファイルを共有できます。最大20MBまでアップロード可能。モデレーター限定共有機能も搭載。

vpn_key

Proxy

フィルタリングを回避してWebサイトにアクセス。複数のプロキシモードで、より多くのサイトに対応します。

screenshot_monitor

Images

Alt+Sでスクリーンショット、Alt+Rで画面録画が可能。撮影した画像や動画は自動で保存され、いつでも確認できます。

piano

Piano

キーボードやマウスでピアノ演奏が楽しめます。録音機能付きで、演奏を保存することも可能です。

stadia_controller

Games

Eaglercraftやしょぼんのアクションなど、人気ゲームが遊べます。リクエストも随時受付中！

security

偽装モード

Meta(検索)+1キーで、画面を瞬時に「まなびポケット」に偽装。緊急時も安心です。
